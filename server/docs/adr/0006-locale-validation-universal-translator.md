# ADR-0006: Universal Translator & Locale Input Validation

* **Status**: Accepted
* **Date**: 2026-08-19

## Context

User input validation errors generated by default validators are often in raw English and contain repetitive field name prefixes (e.g. `"email": "email must be a valid email address"`), creating poor user experience for non-English users or custom UIs.

## Decision

- Integrate `go-playground/validator/v10` with `go-playground/universal-translator` and `go-playground/locales/id` / `locales/en`.
- Support runtime locale selection via `APP_LOCALE` environment variable (default: `id`).
- Register custom field translations so field names are **not repeated** inside error values (e.g. `"full_name": "wajib diisi"` instead of `"full_name": "full_name wajib diisi"`).

## Consequences

### Positive
- Clean, localized, end-user-ready validation messages out of the box.
- Decouples UI validation message formatting from client application code.

### Negative
- Requires registering explicit translator mappings for custom validation rules.
